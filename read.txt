你这个思路实际上已经不是“图片生成工具”，而是一个**AI营销素材生产Agent**了。

我建议不要做成固定流程，而是做成**状态机 + 多轮对话Agent**。

因为用户永远会反复改：

> 产品不够高级
>
> 换年轻女性模特
>
> 换科技感背景
>
> 图2不要展开状态
>
> 视频太快
>
> 重新生成提示词

所以Agent必须拥有记忆和阶段管理。

---

```text
workspace/

```

# 第一阶段

## 用户放产品图

```text

```

Claude Code启动：

```bash
cc start
```

发现：

```python
input/product.jpg
```

存在。

进入：

```text
ANALYZE_PRODUCT
```

---

# 第二阶段

## 图片分析Agent

调用 Claude Superpower

提示词：

```text
分析这张产品图：

输出：

1. 产品类型
2. 材质
3. 使用场景
4. 目标用户
5. 卖点
6. 品牌调性
7. 适合的视频风格

不要生成营销文案。
仅做产品分析。
```

得到：

```json
{
  "type":"智能门铃",
  "material":"ABS塑料",
  "target":"家庭用户",
  "style":"科技感"
}
```

保存：

```json
state/workflow.json
```

# 第三阶段

## Agent开始对话

例如：

```text
我识别到：

产品：智能门铃

请确认：

1. 面向消费者还是企业？
2. 偏科技风还是生活风？
3. 是否需要模特？
4. 视频比例：
   □ 16:9
   □ 9:16
   □ 1:1
```

```text
消费者
科技风
不要模特
9:16
```

# 最终形态

整个流程实际上变成：

```text
用户放产品图
        ↓
Agent分析产品
        ↓
多轮对话确认需求
        ↓
生成图1/图2
        ↓
反复修改直到满意
        ↓
生成视频Prompt
        ↓
用户去即梦生成视频
        ↓
放回video.mp4
        ↓
Agent自动拆帧
        ↓
生成AI IDE工程提示词
        ↓
Claude Code继续建站
```

如果你准备基于 Claude Code + Superpower 插件实现，我建议再增加一个核心文件：

```text
state/workflow.json
```

所有阶段状态、用户确认内容、图片Prompt、视频Prompt全部存进去。

这样即使 Claude Code 中断、重启、上下文丢失，也能从上一次进度继续执行，而不是重新开始整个流程。这一点在实际使用中价值非常高。
