# 结尾帧生成系统设计

## 概述

将图2从"图1的微调"升级为"有意义的结尾帧"，支持 AI 自动推断 + 用户指定的混合模式，适配任何参考图场景。

## 核心流程

```
参考图 → 图1（强约束重绘）
图1 → AI 分析 + 生成 2-3 个结尾方案
用户选择方案 → 图2（基于方案生成）
图1 + 图2 → 视频首尾帧
```

## 结尾方案结构

每个方案包含：
- **类型标签**：动作完成 / 场景拉远 / 情绪变化 / 时间变化 / 互动变化
- **一句话描述**：结尾状态的具体描述
- **Prompt**：对应的图生图 Prompt

### 示例（熊猫吃竹子）

| # | 类型 | 描述 |
|---|------|------|
| 1 | 动作完成 | 熊猫吃完竹子，舔舔嘴巴，满足地坐着 |
| 2 | 场景拉远 | 镜头拉远，熊猫在竹林中，周围是更多竹子 |
| 3 | 情绪变化 | 熊猫抬头看天空，表情从专注变为开心 |
| 4 | 自定义 | 用户描述 |

## 预设模板类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 动作完成 | 当前动作的自然结束 | 有明确动作的图（吃、跑、跳） |
| 场景拉远/推近 | 视角变化，展示更多/更少环境 | 任何场景 |
| 情绪转变 | 主体表情/姿态变化 | 有人物/动物的图 |
| 时间变化 | 白天→夜晚、季节变化 | 有环境背景的图 |
| 互动变化 | 主体与环境/他者的互动变化 | 有多个元素的图 |

## AI 分析逻辑

1. 读取图1，识别核心元素：
   - 主体（人物/动物/物体）
   - 动作（当前正在做什么）
   - 场景（环境、背景）
   - 情绪（表情、氛围）
2. 基于元素推断可能的"下一步"变化
3. 结合预设模板生成 2-3 个结尾方案

## Prompt 生成规则

**强约束保留：**
- 图1的所有特征（角色、服装、色调、构图）
- 只改变结尾方案描述的部分

**明确禁止：**
- 添加方案中未提及的新元素
- 改变方案中未提及的现有元素

**Prompt 结构：**
```
Same [主体] as reference image. [保留所有原始特征的约束]。
Change: [结尾方案描述的具体变化]。
Do NOT add new elements not mentioned above.
Maintain identical art style, color palette, and composition.
```

## 用户交互流程

### CONFIRM_IMAGES 阶段

```
生成图1后，AI 展示结尾方案选项：

请选择结尾帧效果：
1. 【动作完成】熊猫吃完竹子，舔舔嘴巴，满足地坐着
2. 【场景拉远】镜头拉远，熊猫在竹林中，周围是更多竹子
3. 【情绪变化】熊猫抬头看天空，表情从专注变为开心
4. 自定义（描述你想要的结尾）

回复选项，例如：1 或 4、熊猫站起来挥手
```

### 修改选项

生成图1+图2后：
1. 满意，继续
2. 重新选择结尾方案
3. 修改图1（重新生成）
4. 全部重做

```python
        ending_description: 结尾方案的描述

    Returns:
        图生图 Prompt
    """
```

### vibecode-agent.md

更新 CONFIRM_IMAGES 阶段：
- 图1 生成后，调用 `generate_ending_options()` 获取结尾方案
- 展示方案给用户选择
- 用户选择后，调用 `build_ending_prompt()` 生成图2 Prompt
- 调用 `generate_image()` 生成图2

## 错误处理

- AI 无法分析图片 → 提供默认结尾选项（场景拉远）
- 用户自定义描述为空 → 提示重新输入
- 图2 生成失败 → 保留图1，提示重试
