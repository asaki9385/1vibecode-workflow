## 第6页 模块一：状态管理模块 workflow.py 实现（中枢代码）
### 正文内容
模块职责：统一管理运行状态、全局数据、流程重置、断点恢复。
### 核心代码（节选+注释）
```python
class Workflow:
    def __init__(self):
        # 初始化：读取本地状态文件，实现断点续传
        self.current_stage = self.load_stage()
        self.data = self.load_data()

    def get_stage(self):
        """获取当前运行状态"""
        return self.current_stage

    def set_stage(self, stage_name):
        """切换状态，并持久化到本地"""
        self.current_stage = stage_name
        self.save_stage()

    def set_data(self, key, value):
        """存储流程中的临时数据（图片路径、产品信息等）"""
        self.data[key] = value
        self.save_data()

    def reset(self):
        """重置整个工作流到初始状态"""
        self.current_stage = "INIT"
        self.data = {}
```

## 第9页 模块四：视频拆帧模块 frame_extractor.py 实现
### 正文内容
模块职责：调用系统工具FFmpeg，将完整视频拆解为连续帧图片，是帧动画网页的前置步骤。
### 核心实现逻辑
1. Python 使用 `subprocess` 子进程调用本地FFmpeg命令；
2. 按指定帧率拆分视频，批量生成有序命名的图片；
3. 统计总帧数，返回给上层模块使用。

### 核心代码（节选）
```python
def extract_frames(video_path, output_dir, fps=24):
    # 调用系统FFmpeg命令
    cmd = [
        "ffmpeg", "-i", video_path,
        "-vf", f"fps={fps}",
        f"{output_dir}/frame_%03d.jpg"
    ]
    subprocess.run(cmd)
    # 统计生成帧数
    frame_list = os.listdir(output_dir)
    return len(frame_list)
```

# 三、配套教学补充（面向授课）
## 1. 课堂实操任务（聚焦代码实现）
1. 基础任务：读懂五大核心模块代码，标注每一行关键逻辑；
2. 实操任务：修改 `prompt_builder.py`，新增一种结尾帧方案；
3. 进阶任务：在图片生成模块中，补充自定义异常提示。

## 2. 授课小技巧
1. 讲解顺序严格遵循：**架构 → 核心中枢（状态机）→ 分模块 → 模块联动 → 调优测试**，符合软件开发流程；
2. 代码讲解「抓大放小」：只讲**核心逻辑**，跳过工具类、冗余代码；
3. 结合学生已学知识点（Python类、文件操作、网络请求）衔接讲解。

## 3. 页数精简方案（课时不足时）
可合并页面：
- 第6-10页五大模块可合并为2页「核心模块合集」；
- 第14-16页三大技术细节可合并为1页「底层技术优化」。
