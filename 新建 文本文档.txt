给你一个清晰的落地路线，按顺序来：

---

## 第一阶段：环境准备（1小时内搞定）

**1. 安装基础工具**
```bash
# 安装 Python 依赖
pip install requests python-dotenv oss2

# 安装 ffmpeg（macOS）
brew install ffmpeg

# Windows 去 https://www.gyan.dev/ffmpeg/builds/ 下载，解压后加入系统 PATH
```

**2. 申请 API 密钥**

按顺序去申请，两个都需要：
- **Vidu**：去 [platform.vidu.cn](https://platform.vidu.cn) 注册，进控制台创建 API Key
- **阿里云 OSS**：登录阿里云 → 右上角头像 → AccessKey 管理 → 创建，然后开通 OSS 服务，新建一个 Bucket，开启「静态网站托管」

**3. 创建项目文件夹结构**
```
vibecode-workflow/
├── input/          ← 放你的两张图片
├── temp/           ← 脚本自动创建
├── projects/       ← 脚本自动创建
├── .env            ← 你来填
├── requirements.txt
└── run.py
```

**4. 填写 `.env` 文件**
```env
VIDU_API_KEY=你的vidu密钥
ALIBABA_CLOUD_ACCESS_KEY_ID=你的阿里云ID
ALIBABA_CLOUD_ACCESS_KEY_SECRET=你的阿里云密钥
ALIBABA_CLOUD_REGION=cn-hangzhou
ALIBABA_CLOUD_OSS_BUCKET=你的bucket名称
```

## 第二阶段：逐个写脚本（核心步骤）

**按这个顺序写，每写一个就单独测试：**

### Step 1 — 先写拆帧（最简单，无需 API）

新建 `frame_extractor.py`，把这段提示词发给 Claude/Cursor：

```
写一个 Python 函数 extract_frames(video_path, output_dir, fps=24)：
- 用 subprocess 调用 ffmpeg 拆帧
- 输出文件名格式：frame_001.jpg, frame_002.jpg
- output_dir 不存在则自动创建
- 拆帧完成后打印总帧数
- ffmpeg 未安装时打印安装提示并退出
不用第三方库，只用标准库。
```

写完后用一个本地视频测试：
```bash
python -c "from frame_extractor import extract_frames; extract_frames('test.mp4', 'frames_test')"
```

---

### Step 2 — 写 Vidu 视频生成

先去 [platform.vidu.cn/docs](https://platform.vidu.cn) 看一下当前首尾帧接口的真实字段，然后新建 `video_generator.py`，发给 AI 的提示词：

```
根据以下 Vidu API 文档（把你从官网复制的接口说明粘贴在这里），
写一个 Python 函数 generate_transition_video(img1_path, img2_path, prompt, output_path)：
- 读取两张图片转 base64
- 调用首尾帧生成接口
- 轮询任务状态直到完成
- 下载视频到 output_path
- API Key 从环境变量 VIDU_API_KEY 读取
- 包含错误处理和进度打印
```

> 关键：**一定要把 Vidu 官网的接口文档原文粘进去**，不要靠 AI 猜字段名。

测试：
```bash
python -c "from video_generator import generate_transition_video; generate_transition_video('input/img1.jpg', 'input/img2.jpg', '产品从包装到展开的流畅过渡', 'temp/test.mp4')"
```

---

### Step 3 — 写项目文件生成

新建 `project_preparer.py`，提示词：

```
写一个 Python 函数 prepare_project(frames_dir, product_name, product_desc, output_dir)：
1. 在 output_dir/{product_name}/ 下创建目录：assets/frames/
2. 把 frames_dir 里所有 jpg 复制进去
3. 生成 PROMPT.md，包含4个章节：
   - 建站提示词（根据 product_desc 生成，包含页面结构要求）
   - 帧动画提示词（读取 assets/frames/ 实现滚动触发动画）
   - 深色模式提示词
   - 移动端优化提示词
4. 生成 rules.json 包含5条编码规范
全部用中文，utf-8 编码
```

---

### Step 4 — 写阿里云 OSS 部署

新建 `deployer.py`，提示词：

```
写一个 Python 函数 build_and_deploy(project_dir, bucket_name, access_key_id, access_key_secret, region)：
1. subprocess 执行 npm run build，实时打印日志
2. 自动检测 dist/ 或 out/ 哪个存在
3. 用 oss2 库遍历上传所有文件（保持相对路径）
4. 根据文件后缀自动设置 Content-Type（html/css/js/jpg/webp）
5. 上传完成后打印网站地址和文件总数
用 oss2 库，不用 aliyunsdkoss
```

---

### Step 5 — 整合主入口

所有单独测试通过后，新建 `run.py`，提示词：

```
整合以下4个模块写主脚本：
from video_generator import generate_transition_video
from frame_extractor import extract_frames
from project_preparer import prepare_project
from deployer import build_and_deploy

用 argparse 接收参数：--img1 --img2 --product --desc --prompt --fps --site-name
从 .env 加载环境变量
按顺序执行4步，每步前打印带 emoji 的进度
任意步骤失败则停止并打印错误
最后清理 temp/ 临时文件夹
```

## 第三阶段：测试 → 打包分享

**完整测试一次：**
```bash
python run.py \
  --img1 input/img1.jpg \
  --img2 input/img2.jpg \
  --product "测试产品" \
  --desc "一款高端智能产品" \
  --prompt "平滑的电影级过渡动画，展示产品从包装到展开"
```

**打包给团队：**
```bash
pip freeze > requirements.txt
```

附上这份 README 给团队成员：
1. 克隆项目
2. `pip install -r requirements.txt`
3. 安装 ffmpeg
4. 复制 `.env.example` 为 `.env` 填入密钥
5. 准备两张图，运行 `python run.py ...`
